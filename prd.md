# PRD (Product Requirements Document): Mini Pixel Vault & To-Do Dashboard

**Author:** Aditya "Diditt" Prayoga  
**Assisted by:** Light (Kiro)  
**Project Name:** Mini Pixel Vault & To-Do Dashboard  
**Version:** 1.1.0  

---

## 1. 🎯 Tujuan Proyek (Objective)
Membangun web aplikasi *solo project* pertama yang menggabungkan hobi pixel art (6 hewan resmi: Ayam, Beruang, Gorila, Kucing, Monyet, Rubah) dengan manajemen tugas belajar (To-Do List) dan fitur **User Profile & Avatar Selection** menggunakan arsitektur modern **Frontend (HTML/CSS/JS) + Database (Supabase)**.

---

## 2. 👥 Target Pengguna (Target Users)
- **Primary:** Aditya "Diditt" Prayoga (sebagai developer & pengguna utama).
- **Secondary:** Teman-teman komunitas USRC (Raken, Iwan, dll.) untuk review dan pameran karya.

---

## 3. ✨ Fitur Utama (Core Features)
1. **Pixel Art Vault (Galeri Hewan Pixel Resmi):**
   - Menampilkan koleksi 6 hewan pixel resmi buatan Adit (Ayam, Beruang, Gorila, Kucing, Monyet, Rubah).
   - Menampilkan detail aset WebP dengan gaya retro pixelated yang tajam.
2. **Interactive To-Do Dashboard:**
   - Menambahkan, mencentang, dan menghapus tugas belajar secara *real-time* ke **Supabase Database**.
3. **User Profile & Avatar Selection (Fitur Baru):**
   - Menampilkan kartu profil pengguna.
   - Memungkinkan pengguna memilih salah satu hewan dari Pixel Vault untuk dijadikan **Avatar Profil Aktif**.

---

## 4. 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+, Supabase JS Client).
- **Backend / Database:** Supabase (PostgreSQL Cloud Database).
- **Deployment:** GitHub Pages.
